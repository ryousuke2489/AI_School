# 生成AI講座 動画編集方針書

## 1. コース概要

本方針書は、全5講義で構成される「生成AI教材コース」の動画編集における統一的なガイドラインを定めるものです。教育系YouTubeチャンネルとしての品質・一貫性を維持しつつ、受講者にとって分かりやすく、飽きさせない動画を制作することを目的とします。

- **コース名**: 生成AI入門 -- 基礎から実践まで
- **全講義数**: 全5講
- **1動画あたりの目標尺**: 約30分（28〜32分を許容範囲とする）
- **対象視聴者**: ビジネスパーソン・大学生（専門知識不要）
- **配信プラットフォーム**: YouTube（16:9、1920x1080 フルHD）

## 3. 画面構成の基本パターン

### パターン一覧

#### パターンA: 講師ワイプ + スライド
```
┌──────────────────────────────┐
│                              │
│      スライド領域             │
│      (メインコンテンツ)        │
│                              │

│                    │ 講師   ││
│                    │ ワイプ ││
│                    └────────┘│

```
- **使用場面**: 通常の講義パート（最も多用するパターン）
- **講師ワイプサイズ**: 画面右下、横幅の約20%
- **ワイプ形状**: 角丸長方形、薄い白枠付き

#### パターンB: スライドフルスクリーン
```
┌──────────────────────────────┐
│                              │
│      スライド領域             │

│                              │
│                              │

```
- **使用場面**: 図解・チャート・比較表の表示、重要な概念の説明時

#### パターンC: デモ画面 + 講師ワイプ
```
┌──────────────────────────────┐
│                              │
│      デモ画面                 │

│                    └────────┘│

```
- **使用場面**: AIツールの実演、ブラウザでの操作デモ
- **補足**: マウスカーソルを強調表示（黄色ハイライトリング）

#### パターンD: 講師フルショット
```
┌──────────────────────────────┐
│                              │
│         講師                 │

- **使用場面**: オープニング挨拶、まとめ、重要メッセージの強調
- **背景**: 薄いボケ処理またはバーチャル背景（落ち着いたオフィス風）

#### パターンE: 2カラム比較
```
┌──────────────┬───────────────┐
│              │               │

- **中央に区切り線**: 白の細線（1px）

## 4. テロップ表示ルール

### 4.1 テロップの種類

| 種別 | 表示位置 | フォントサイズ | 色 | 背景 | 用途 |
|------|----------|--------------|-----|------|------|
| キーワード強調 | 画面下部中央 | 48px Bold | 白 | ネイビー半透明帯(80%) | 重要用語の初出時 |
| 補足説明 | 画面下部中央 | 36px Regular | 白 | ダークグレー半透明帯(70%) | 講師の発言を補足する情報 |
| セクションタイトル | 画面上部左寄せ | 42px Bold | ネイビー | 白半透明帯(90%) | 新しいセクション開始時 |
| 数値・データ | 画面中央 | 56px Bold | コーラルオレンジ | なし（ドロップシャドウ付き） | 印象的な数字・統計 |
| 英語用語 | キーワードの下 | 28px Regular | ライトグレー | なし | 英語の原語表記 |

### 4.2 表示ルール

- **表示時間**: 最低3秒、最大8秒（文字数に応じて調整）
- **表示アニメーション**: フェードイン（0.3秒）→ 表示 → フェードアウト（0.3秒）
- **同時表示上限**: テロップは最大2種類まで同時表示可（例: セクションタイトル + キーワード強調）
- **表示頻度**: 1分あたり3〜5回を目安（多すぎると散漫になる）
- **キーワード初出ルール**: 各講義のキーワード一覧に含まれる用語は初出時に必ずキーワード強調テロップを表示

### 4.3 テロップデザイン詳細

- **テロップ帯の角丸**: 8px
- **テロップ帯の左右パディング**: 24px
- **テロップ帯の上下パディング**: 12px
- **ドロップシャドウ**: 2px 2px 4px rgba(0,0,0,0.3)
- **文字の縁取り**: なし（帯背景で可読性を確保）

## 5. BGM/SE（効果音）ガイドライン

### 5.1 BGM

| 区間 | BGMタイプ | 音量目安 | 備考 |
|------|-----------|----------|------|
| オープニング（0:00〜0:30） | アップテンポ・テック系 | -12dB | 講座のテーマ曲として全講義共通 |
| 通常講義パート | Lo-Fi / アンビエント系 | -24dB〜-28dB | 講師の声を邪魔しない程度。ほぼ聞こえないレベル |
| セクション切り替え時 | 短いジングル（2〜3秒） | -14dB | セクション間の区切りを明確に |
| デモ・実演パート | 軽快なBGM | -22dB | 少しテンポを上げて集中感を演出 |
| まとめパート | 穏やかなピアノ系 | -20dB | 振り返りの落ち着いた雰囲気 |
| エンディング（ラスト30秒） | オープニングと同じテーマ曲 | -12dB → フェードアウト | 統一感を持たせて締める |

### 5.2 SE（効果音）

| SE名 | 使用タイミング | 音量目安 |
|------|--------------|----------|
| ポップ音（ポン） | キーワードテロップ表示時 | -16dB |
| スライド切替音（シュッ） | スライドのページ送り時 | -20dB |
| 正解音（ピンポン） | 正しい例・良い事例の紹介時 | -16dB |
| 不正解音（ブブー） | 悪い例・アンチパターンの紹介時 | -16dB |
| 注意音（チーン） | 注意点・警告の表示時 | -16dB |
| クリック音 | デモ画面でのクリック操作時 | -20dB |
| タイピング音 | プロンプト入力デモ時 | -22dB |
| 区切りジングル | セクション切り替え時 | -14dB |

### 5.3 音声に関する注意

- **講師音声の音量**: -6dB〜-3dB（基準レベル）
- **ラウドネス基準**: -14 LUFS（YouTube推奨値）
- **BGMは講師発言中にダッキング**: 講師の音声検出時にBGMを-4dB自動低減
- **SE使用頻度**: 1分あたり最大3回程度（過度な使用は避ける）

## 6. アニメーション・トランジション方針

### 6.1 画面切り替え（トランジション）

| トランジション | 使用場面 | 持続時間 |
|--------------|----------|----------|
| クロスフェード | 通常のスライド切り替え | 0.5秒 |
| スライドイン（左から右） | 新しいセクションの開始 | 0.4秒 |
| カット（直切り） | テンポよく進む場面、デモ画面切替 | 即時 |
| ズームイン | 重要ポイントの強調時 | 0.6秒 |
| ワイプ | セクション間の大きな切り替え | 0.5秒 |

### 6.2 スライド内アニメーション

| アニメーション | 使用場面 | 持続時間 |
|--------------|----------|----------|
| フェードイン | 箇条書きの順次表示 | 0.3秒/項目 |
| スケールアップ | 重要キーワードの強調 | 0.4秒 |
| パスアニメーション | 矢印・フロー図の描画 | 0.8〜1.2秒 |
| ハイライト（枠線点滅） | 図解の特定部分への注目誘導 | 1.0秒（2回点滅） |
| 数値カウントアップ | 統計データの表示 | 1.5秒 |

### 6.3 禁止事項

- スターワイプなどの派手すぎるトランジションは使用しない
- 3D回転などの過剰なアニメーションは避ける
- アニメーションの持続時間が2秒を超えないようにする
- 同時に3つ以上のアニメーションを重ねない

## 9. 品質チェックリスト

編集完了後、各動画について以下をチェックします。

- [ ] 動画尺が28〜32分の範囲内に収まっている
- [ ] 音声レベルが-14 LUFS基準に収まっている
- [ ] キーワード初出時にテロップが表示されている
- [ ] テロップに誤字脱字がない
- [ ] BGMが講師音声を妨げていない
- [ ] トランジションが統一的に使用されている
- [ ] サムネイルがスマートフォンサイズでも視認できる
- [ ] オープニング・エンディングが全講義で統一されている
- [ ] 無音区間が3秒以上続いていない（意図的な間は除く）
- [ ] 画面構成パターンが適切に使い分けられている
