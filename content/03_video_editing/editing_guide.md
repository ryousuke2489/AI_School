# 生成AI講座 動画編集方針書

## 1. コース概要

本方針書は、全5講義で構成される「生成AI教材コース」の動画編集における統一的なガイドラインを定めるものです。教育系YouTubeチャンネルとしての品質・一貫性を維持しつつ、受講者にとって分かりやすく、飽きさせない動画を制作することを目的とします。

- **コース名**: 生成AI入門 -- 基礎から実践まで
- **全講義数**: 全5講
- **1動画あたりの目標尺**: 約30分（28〜32分を許容範囲とする）
- **合計コース時間**: 約150分（2時間30分）
- **対象視聴者**: ビジネスパーソン・大学生（専門知識不要）
- **配信プラットフォーム**: YouTube（16:9、1920x1080 フルHD）
- **難易度の流れ**: 概念理解 → 技術理解 → 実践スキル → 応用力 → 批判的思考

### 1.1 講義一覧と概要

| 講義 | タイトル | 主なテーマ | 想定時間 |
|------|----------|-----------|----------|
| 第1講 | 生成AIとは何か -- 概要と歴史 | 定義・歴史・代表サービス・社会的インパクト | 30分 |
| 第2講 | 大規模言語モデル（LLM）の仕組み | 次単語予測・Transformer・学習プロセス・能力と限界 | 30分 |
| 第3講 | プロンプトエンジニアリング入門 | プロンプト設計・Zero/Few-shot・CoT・実践演習 | 30分 |
| 第4講 | 生成AIのビジネス活用事例 | 部門別活用・導入課題・ツール選定 | 30分 |
| 第5講 | 生成AIの倫理・リスク・未来 | 倫理課題・法規制・ディープフェイク・未来展望 | 30分 |

## 2. トーン＆マナー

### 2.1 全体トーン

| 項目 | 方針 |
|------|------|
| 語り口 | 親しみやすく丁寧。敬語ベースだが堅すぎない。「一緒に学んでいきましょう」というスタンス |
| テンポ | 適度にテンポよく。冗長な間は詰める。重要ポイントは少し溜めて強調 |
| 雰囲気 | 知的好奇心を刺激する明るいトーン。TED Talk風の「学びが楽しい」感覚 |
| ターゲット意識 | 専門知識ゼロの視聴者でも安心して視聴できる。専門用語は初出時に必ず解説を添える |
| カラーパレット | メインカラー: ネイビー(#1B2A4A) / アクセント: コーラルオレンジ(#FF6B4A) / サブ: ライトグレー(#F5F5F5) / 背景ベース: ホワイト(#FFFFFF) |
| フォント | テロップ: Noto Sans JP Bold / 補足テキスト: Noto Sans JP Regular / 英語: Inter |

### 2.2 講義ごとのトーン調整

| 講義 | トーン | 演出のポイント |
|------|--------|--------------|
| 第1講（概要と歴史） | ワクワク感重視 | 「これから学ぶ世界」への期待感を演出。歴史年表はタイムライン風アニメーションで視覚化。代表的なAIサービスの画面キャプチャを多用 |
| 第2講（LLMの仕組み） | 知的探究型 | 図解を多用して「なるほど！」を引き出す。Transformer・Attentionの概念図は段階的に組み立てるアニメーションで。数式は極力避け、直感的な比喩を重視 |
| 第3講（プロンプト） | 実践・ハンズオン感 | 「一緒にやってみよう」のライブ感。画面上でプロンプトをリアルタイムに入力するデモを多用。良い例/悪い例の比較を並べて表示 |
| 第4講（ビジネス活用） | リアリティ重視 | 事例紹介でリアリティを演出。「自分もできそう」感。業種・部門ごとの事例をアイコンやピクトグラムで視覚的に整理 |
| 第5講（倫理・未来） | 落ち着き・深み | 考えさせる間を大切に。ニュース映像風の画面構成も取り入れる。ただし最後は「未来への希望」で前向きに締める |

## 3. 画面構成の基本パターン

### パターン一覧

#### パターンA: 講師ワイプ + スライド（標準レイアウト）
```
┌──────────────────────────────┐
│                              │
│      スライド領域             │
│      (メインコンテンツ)        │
│                              │
│                    ┌────────┐│
│                    │ 講師   ││
│                    │ ワイプ ││
│                    └────────┘│
└──────────────────────────────┘
```
- **使用場面**: 通常の講義パート（最も多用するパターン。各動画の50〜60%を占める）
- **講師ワイプサイズ**: 画面右下、横幅の約20%
- **ワイプ形状**: 角丸長方形（角丸半径8px）、薄い白枠付き（2px）
- **ワイプ背景**: 講師背後はボケ処理またはバーチャル背景

#### パターンB: スライドフルスクリーン
```
┌──────────────────────────────┐
│                              │
│      スライド領域             │
│      (フルスクリーン)          │
│                              │
│                              │
└──────────────────────────────┘
```
- **使用場面**: 図解・チャート・比較表の表示、情報量の多い概念の説明時
- **講師ワイプ**: 非表示
- **使用比率**: 各動画の15〜25%

#### パターンC: デモ画面 + 講師ワイプ
```
┌──────────────────────────────┐
│                              │
│      デモ画面                 │
│      (ブラウザ/ツール画面)     │
│                              │
│                    ┌────────┐│
│                    │ 講師   ││
│                    │ ワイプ ││
│                    └────────┘│
└──────────────────────────────┘
```
- **使用場面**: AIツールの実演、ブラウザでの操作デモ（特に第3講・第4講で多用）
- **補足**: マウスカーソルを強調表示（黄色ハイライトリング）。クリック時にはリップルエフェクトを追加
- **ズーム対応**: 操作箇所が小さい場合は、該当部分を拡大表示する「ズームインセット」を使用

#### パターンD: 講師フルショット
```
┌──────────────────────────────┐
│                              │
│         講師                 │
│      (バストアップ)           │
│                              │
│                              │
└──────────────────────────────┘
```
- **使用場面**: オープニング挨拶、まとめ、重要メッセージの強調、問いかけの場面
- **背景**: 薄いボケ処理またはバーチャル背景（落ち着いたオフィス風）
- **使用比率**: 各動画の10〜15%（冒頭・末尾 + 要所での強調）

#### パターンE: 2カラム比較
```
┌──────────────┬───────────────┐
│              │               │
│   左側       │   右側        │
│   (比較A)    │   (比較B)     │
│              │               │
│              │               │
└──────────────┴───────────────┘
```
- **使用場面**: 2つの概念・手法・ツールの比較（識別型AI vs 生成型AI、良いプロンプト vs 悪いプロンプトなど）
- **中央に区切り線**: 白の細線（1px）
- **ヘッダー部**: 各カラム上部にラベルを配置（ネイビー背景 + 白文字）

#### パターンF: タイムライン / フロー表示
```
┌──────────────────────────────┐
│ ●──────●──────●──────●────── │
│        ↑                     │
│   [説明テキスト]              │
│                              │
│                              │
└──────────────────────────────┘
```
- **使用場面**: 歴史年表（第1講）、学習プロセスの流れ（第2講）、ワークフロー（第4講）
- **アニメーション**: 左から右へ順次ハイライトしながら進行

## 4. テロップ表示ルール

### 4.1 テロップの種類

| 種別 | 表示位置 | フォントサイズ | 色 | 背景 | 用途 |
|------|----------|--------------|-----|------|------|
| キーワード強調 | 画面下部中央 | 48px Bold | 白(#FFFFFF) | ネイビー半透明帯(80%) | 重要用語の初出時 |
| 補足説明 | 画面下部中央 | 36px Regular | 白(#FFFFFF) | ダークグレー半透明帯(70%) | 講師の発言を補足する情報 |
| セクションタイトル | 画面上部左寄せ | 42px Bold | ネイビー(#1B2A4A) | 白半透明帯(90%) | 新しいセクション開始時 |
| 数値・データ | 画面中央 | 56px Bold | コーラルオレンジ(#FF6B4A) | なし（ドロップシャドウ付き） | 印象的な数字・統計 |
| 英語用語 | キーワードの下 | 28px Regular | ライトグレー(#AAAAAA) | なし | 英語の原語表記 |
| 注意喚起 | 画面中央やや上 | 40px Bold | 白(#FFFFFF) | コーラルオレンジ帯(90%) | 注意点・よくある誤解の訂正 |

### 4.2 表示ルール

- **表示時間**: 最低3秒、最大8秒（文字数に応じて調整。目安: 1文字あたり0.3秒 + 基底2秒）
- **表示アニメーション**: フェードイン（0.3秒）→ 表示 → フェードアウト（0.3秒）
- **同時表示上限**: テロップは最大2種類まで同時表示可（例: セクションタイトル + キーワード強調）
- **表示頻度**: 1分あたり3〜5回を目安（多すぎると散漫になる）
- **キーワード初出ルール**: カリキュラムのキーワード一覧に含まれる用語は初出時に必ずキーワード強調テロップを表示し、英語原語テロップを併記する

### 4.3 講義ごとの主要キーワード（テロップ必須）

テロップ表示が必須となる、各講義のキーワードは以下の通りです。

| 講義 | 主要キーワード |
|------|--------------|
| 第1講 | 生成AI（Generative AI）、識別型AI、GAN（敵対的生成ネットワーク）、Transformer、GPT、拡散モデル（Diffusion Model）、基盤モデル（Foundation Model） |
| 第2講 | 大規模言語モデル（LLM）、Self-Attention（自己注意機構）、トークン、事前学習（Pre-training）、ファインチューニング（Fine-tuning）、RLHF、ハルシネーション、創発的能力（Emergent Abilities） |
| 第3講 | プロンプトエンジニアリング、Zero-shotプロンプティング、Few-shotプロンプティング、Chain of Thought（CoT）、ロールプロンプティング、Temperature、ReAct |
| 第4講 | RAG（検索拡張生成）、AIエージェント、API連携、コパイロット（Copilot）、ROI（投資対効果）、PoC（概念実証） |
| 第5講 | AIバイアス、著作権、ディープフェイク、責任あるAI（Responsible AI）、EU AI規制法（AI Act）、AGI（汎用人工知能）、アライメント（Alignment） |

### 4.4 テロップデザイン詳細

- **テロップ帯の角丸**: 8px
- **テロップ帯の左右パディング**: 24px
- **テロップ帯の上下パディング**: 12px
- **ドロップシャドウ**: 2px 2px 4px rgba(0,0,0,0.3)
- **文字の縁取り**: なし（帯背景で可読性を確保）
- **行間**: 1.4em（複数行テロップの場合）

## 5. BGM/SE（効果音）ガイドライン

### 5.1 BGM

| 区間 | BGMタイプ | 音量目安 | 備考 |
|------|-----------|----------|------|
| オープニング（0:00〜0:30） | アップテンポ・テック系 | -12dB | 講座のテーマ曲として全講義共通。シリーズの統一感を最も強く印象づける要素 |
| 通常講義パート | Lo-Fi / アンビエント系 | -24dB〜-28dB | 講師の声を邪魔しない程度。ほぼ聞こえないレベル |
| セクション切り替え時 | 短いジングル（2〜3秒） | -14dB | セクション間の区切りを明確に。全講義で同一のジングルを使用 |
| デモ・実演パート | 軽快なBGM | -22dB | 少しテンポを上げて集中感を演出 |
| まとめパート | 穏やかなピアノ系 | -20dB | 振り返りの落ち着いた雰囲気 |
| エンディング（ラスト30秒） | オープニングと同じテーマ曲 | -12dB → フェードアウト | 統一感を持たせて締める |

### 5.2 SE（効果音）

| SE名 | 使用タイミング | 音量目安 | 備考 |
|------|--------------|----------|------|
| ポップ音（ポン） | キーワードテロップ表示時 | -16dB | 明るくソフトな音色 |
| スライド切替音（シュッ） | スライドのページ送り時 | -20dB | 控えめ。毎回ではなくセクション切替時のみ |
| 正解音（ピンポン） | 正しい例・良い事例の紹介時 | -16dB | 第3講のプロンプト比較で多用 |
| 不正解音（ブブー） | 悪い例・アンチパターンの紹介時 | -16dB | 第3講のアンチパターン紹介で使用 |
| 注意音（チーン） | 注意点・警告の表示時 | -16dB | 第5講の倫理・リスク解説で多用 |
| クリック音 | デモ画面でのクリック操作時 | -20dB | 第3講・第4講のデモパートで使用 |
| タイピング音 | プロンプト入力デモ時 | -22dB | 第3講で特に多用。リアルなキーボード音 |
| 区切りジングル | セクション切り替え時 | -14dB | 全講義共通の短いメロディ |
| カウントアップ音 | 数値データ表示時 | -18dB | 統計やデータの強調に使用 |

### 5.3 音声に関する基準

- **講師音声の音量**: -6dB〜-3dB（基準レベル）
- **ラウドネス基準**: -14 LUFS（YouTube推奨値）
- **BGMダッキング**: 講師の音声検出時にBGMを-4dB自動低減（アタック: 50ms、リリース: 500ms）
- **SE使用頻度**: 1分あたり最大3回程度（過度な使用は避ける）
- **無音区間**: 意図的な間を除き、3秒以上の無音区間を作らない
- **ノイズ処理**: 収録音声には事前にノイズリダクション処理を適用（ノイズゲート閾値: -40dB）

## 6. アニメーション・トランジション方針

### 6.1 画面切り替え（トランジション）

| トランジション | 使用場面 | 持続時間 |
|--------------|----------|----------|
| クロスフェード | 通常のスライド切り替え | 0.5秒 |
| スライドイン（左から右） | 新しいセクションの開始 | 0.4秒 |
| カット（直切り） | テンポよく進む場面、デモ画面切替 | 即時 |
| ズームイン | 重要ポイントの強調時 | 0.6秒 |
| ワイプ | セクション間の大きな切り替え | 0.5秒 |

### 6.2 スライド内アニメーション

| アニメーション | 使用場面 | 持続時間 |
|--------------|----------|----------|
| フェードイン | 箇条書きの順次表示 | 0.3秒/項目 |
| スケールアップ | 重要キーワードの強調 | 0.4秒 |
| パスアニメーション | 矢印・フロー図の描画 | 0.8〜1.2秒 |
| ハイライト（枠線点滅） | 図解の特定部分への注目誘導 | 1.0秒（2回点滅） |
| 数値カウントアップ | 統計データの表示 | 1.5秒 |
| タイムライン進行 | 歴史年表・プロセスフローの進行 | 各ノード0.5秒 |
| 比較スライドイン | 2カラム比較時に左右からスライドイン | 0.4秒 |

### 6.3 講義別のアニメーション重点

| 講義 | 重点的に使用するアニメーション |
|------|--------------------------|
| 第1講 | タイムライン進行（AI歴史年表）、スケールアップ（代表サービス紹介） |
| 第2講 | パスアニメーション（Transformer構造図）、フェードイン（学習プロセスの段階表示） |
| 第3講 | 比較スライドイン（良い/悪いプロンプトの対比）、タイピングアニメーション（プロンプト入力演出） |
| 第4講 | フェードイン（活用領域マップの段階表示）、数値カウントアップ（ROI・コスト数値） |
| 第5講 | ハイライト（リスク項目の強調）、スケールアップ（未来展望のキーメッセージ） |

### 6.4 禁止事項

- スターワイプなどの派手すぎるトランジションは使用しない
- 3D回転などの過剰なアニメーションは避ける
- アニメーションの持続時間が2秒を超えないようにする
- 同時に3つ以上のアニメーションを重ねない
- 画面全体が激しく動く演出は避ける（視聴者の目の負担軽減）

## 7. サムネイルデザイン方針

### 7.1 基本レイアウト

```
┌──────────────────────────────┐
│ [講義番号]                    │
│                              │
│   大きなキャッチコピー         │
│   （2行以内）                 │
│                              │
│              ┌──────────┐    │
│              │ 講師写真  │    │
│              │ (切り抜き) │    │
│              └──────────┘    │
│          [コース名ロゴ]       │
└──────────────────────────────┘
```

### 7.2 デザインルール

| 項目 | 仕様 |
|------|------|
| サイズ | 1280x720px |
| 背景 | グラデーション（ネイビー #1B2A4A → ダークブルー #0D1B2A） |
| キャッチコピー | 最大2行、72px以上の太字（Noto Sans JP Black）、白またはコーラルオレンジ |
| 講師写真 | 右側に配置、背景切り抜き、明るい表情。講義内容に合った表情・ポーズ |
| 講義番号 | 左上に配置、コーラルオレンジ(#FF6B4A)の丸バッジ（直径80px）内に白文字 |
| コース名 | 下部にシリーズ共通のロゴバー（ネイビー帯 + 白文字「生成AI入門」） |
| 文字の視認性 | スマートフォンの小さなサムネイルでも読めること。文字にはドロップシャドウ必須 |
| アイキャッチアイコン | 講義テーマに関連するアイコンを1つ配置（例: 第1講はAIロボット、第3講はチャット吹き出し） |

### 7.3 各講義のサムネイルキャッチコピー

| 講義 | キャッチコピー | アイキャッチアイコン |
|------|--------------|-------------------|
| 第1講 | AIが「創る」時代へ -- 生成AIの全貌 | ロボット＋スパークル |
| 第2講 | AIはどう考える？ LLMの仕組みを解剖 | 脳＋ネットワーク図 |

## 9. アクセシビリティへの配慮

| 項目 | 対応方針 |
|------|---------|
| 字幕 | YouTube自動字幕に加え、手動で修正した日本語字幕ファイル（.srt）を全講義に付与 |
| テロップの可読性 | フォントサイズ最低28px以上。コントラスト比4.5:1以上を確保 |
| 色覚多様性 | 赤/緑の組み合わせのみで情報を区別しない。形状やラベルも併用する |
| 読み上げ速度 | 講師の話速は1分あたり280〜320文字を目安とする |
| チャプター機能 | YouTube概要欄にタイムスタンプ付きチャプターを設定 |

## 10. 品質チェックリスト

編集完了後、各動画について以下をチェックします。

### 10.1 映像チェック

- [ ] 動画尺が28〜32分の範囲内に収まっている
- [ ] オープニング・エンディングが全講義で統一されている
- [ ] 画面構成パターンが適切に使い分けられている
- [ ] 講師ワイプの位置・サイズが統一されている
- [ ] スライド上の文字がフルHDで読めるサイズになっている
- [ ] 2カラム比較の場合、両カラムの情報量バランスが取れている
- [ ] デモ画面のマウスカーソルが強調表示されている

### 10.2 音声チェック

- [ ] 音声レベルが-14 LUFS基準に収まっている
- [ ] BGMが講師音声を妨げていない（ダッキングが正常動作）
- [ ] SE使用頻度が過剰でない（1分あたり3回以下）
- [ ] 無音区間が3秒以上続いていない（意図的な間は除く）
- [ ] ノイズリダクション処理が適用されている

### 10.3 テロップ・テキストチェック

- [ ] カリキュラムのキーワード初出時にテロップが表示されている
- [ ] キーワードテロップに英語原語が併記されている
- [ ] テロップに誤字脱字がない
- [ ] テロップの表示時間が適切である（短すぎず長すぎず）
- [ ] セクションタイトルテロップが各セクション冒頭に表示されている

### 10.4 アニメーション・トランジションチェック

- [ ] トランジションが統一的に使用されている
- [ ] 禁止事項に該当するアニメーションが使用されていない
- [ ] アニメーションの持続時間が2秒以内に収まっている

### 10.5 サムネイル・メタデータチェック

- [ ] サムネイルがスマートフォンサイズ（横幅168px相当）でも視認できる
- [ ] サムネイルのカラーパレットがシリーズ全体で統一されている
- [ ] YouTubeチャプター用のタイムスタンプが設定されている
- [ ] 日本語字幕ファイル（.srt）が準備されている

### 10.6 コンテンツ整合性チェック

- [ ] スライドの内容が台本の該当箇所と一致している
- [ ] テロップのキーワードがカリキュラムのキーワード一覧と一致している
- [ ] 次回予告の内容が次講義の内容と整合している
- [ ] 講義番号・タイトルに誤りがない

## 12. 納品・レビューフロー

### 12.1 制作フロー

```
台本・スライド確定 → 収録 → 粗編集 → テロップ・SE挿入 → 品質チェック → レビュー → 修正 → 最終書き出し
```

### 12.2 レビュー観点

| レビュー担当 | 確認観点 |
|------------|---------|
| 動画編集担当（セルフチェック） | 品質チェックリスト（セクション10）の全項目 |
| 台本担当 | テロップの正確性、ナレーションとの同期 |
| 資料作成担当 | スライド表示の正確性、アニメーションタイミング |
| 構成担当 | 全体構成の整合性、講義間の一貫性 |

### 12.3 改訂管理

- 編集プロジェクトはバージョン番号を付与して管理する（v1, v2, ...）
- レビュー指摘事項は修正内容とともに記録する
- 最終版は `_final` サフィックスを付与して書き出す
